# Sport Data SET wiki

Working wiki for Berner Cup / WAKO Switzerland event ops.

This is the Sport Data SET OVR kickboxing event workflow, v12.2. Software: Kickboxing Administration Mode. Lucas's build is v12.2.0 build 3. Older knowledge-base screenshots are v10 and often do not match this build.

A page from a live screen goes in only after the click-path has been confirmed on his screen. The event-day pages come from the process document he added on 3 Oct 2026.

Open [index.html](index.html) for the sidebar wiki. GitHub Pages can serve this repo from the root.
