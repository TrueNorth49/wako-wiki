# Tatamis

Source: process document added 3 Oct 2026.

Ring draws, draw records, and match calling: [Ring](ring.md).

## Draws

Draw, then Generate draw by selection, and select the tatami categories.

If draws already exist, use Select draws not done so you do not overwrite or regenerate them.

## Draw records

Draw records, then Save draws as draw records by selection. Select the tatami categories.

Also use Select draws not saved as draw records, so existing records are not overwritten.

## Print

List, then All draw records as PDF. Select the areas you want for that day.

For the big overview, use Show / Print / Save by (the second option). That makes a short list per area, in time order, so people can see the plan.
