# Extra match

Lucas stated this path on 4 Oct 2026, after matches had already started.

Do this on a new _copy category. Do not generate or save draw records for categories that already have results.

1. On the left-hand menu, open Categories of this event. Right-click Categories of this event and choose the option to open it.
2. The list of categories for the event opens.
3. Highlight the category to copy. Click Copy data. SET creates a new category whose name ends in _copy. That category is now part of the event.
4. Right-click Individual or team entries, then Move entries. Do not use a path through Individuals. He corrected himself: he did not right-click and choose Individuals.
5. Load the source category, find the people, set Take from and Move to, and check Copy entries. Copy entries keeps the athletes in the old category and also puts them in the new one.
6. He then manually created the draw record for that new category only. He did not say which menu item he used for the draw record.
